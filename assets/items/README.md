Картинки товаров
================

Положите PNG-файлы товаров в эту папку. Если файла нет, игра покажет старую встроенную CSS-иконку.

Имена файлов:

- `fish.png` — рыба
- `hide.png` — шкура
- `axe.png` — топор
- `grain.png` — мешок зерна
- `clay.png` — глина
- `pot.png` — горшок
- `honey.png` — мед
- `cloth.png` — ткань
- `horseshoe.png` — подкова
- `wax.png` — свеча
- `net.png` — сеть
- `coat-item.png` — кафтан
- `knife.png` — нож
- `coin.png` — монета
