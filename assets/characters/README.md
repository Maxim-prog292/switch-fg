Картинки персонажей
===================

Положите изображения персонажей в эту папку. Нужная пропорция кадра: 16:9.

Поддерживаются расширения: `.png`, `.jpg`, `.jpeg`, `.webp`.

Имена файлов:

- `ivan`
- `smith`
- `hunter`
- `potter`
- `miller`
- `farrier`
- `weaver`
- `beekeeper`
- `merchant`
- `tailor`
- `candler`
- `fisher`

Пример: `ivan.png` или `ivan.jpg`.
